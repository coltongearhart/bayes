The frequentist and Bayesian regression models produced very similar point and interval estimates because a noninformative prior was used. With a noninformative prior, the posterior distribution is dominated by the likelihood, so the Bayesian posterior closely resembles the sampling distribution of the least squares estimator. As a result, the posterior means and credible intervals are nearly identical to the least squares estimates and confidence intervals. However, their interpretations differ:

  • A 95% confidence interval is a procedure that captures the true parameter in repeated samples 95% of the time.

  • Whereas a 95% credible interval indicates there is a 95% posterior probability that the parameter lies within the interval, given the observed data and prior.

Part b

Now suppose that the measurements from the calcium group are from a normal population with a known variance (\(\sigma^2 = 8\)). If we want to test that \(H_0\): \(\mu_{\text{calcium}} \le 2\) vs. \(H_A\): \(\mu_{\text{calcium}} > 2\), please find the posterior probability for the null hypothesis to decide if \(H_0\) is supported by the findings. Please use \(\mu_{\text{calcium}} \sim N(0,10^2)\) as the prior distribution in your analysis.

This problem can be solved theoretically because the exact function for the posterior distribution of \(mu_c\) is known in this situation (known \(\sigma^2\) and a normal prior); it was derived in earlier notes.

\[ p(\mu \mid \mathbf{y}) \sim N(\mu_n, \tau^2_n), \quad \text{< where } \mu_n \text{ and } \tau^2_n \text{ have long formulas... >} \]

# initialize items
sigma2 <- 8
mu_0 <- 0
tau_0 <- 10

# calculate parameters for posterior distribution of mu
post_mu <- (length(data_calcium) / sigma2 + 1 / tau_0^2)^(-1) * (length(data_calcium) * mean(data_calcium) / sigma2 + mu_0 / tau_0^2)
post_tau2 <- (length(data_calcium) / sigma2 + 1 / tau_0^2)^(-1)

# find probability the posterior probability for the null hypothesis
pnorm(2, mean = post_mu, sd = sqrt(post_tau2))

Part c

Suppose that the measurements from both groups are random samples from two independent normal populations with a known common variance, \(\sigma^2 = 8\)$. And we want to test that \(H_0\): \(\mu_{\text{calcium}} = \mu_{\text{plaecebo}} = 2\) vs. \(H_A\): \(\mu_{\text{calcium}} = \mu_{\text{plaecebo}} = 0\). Could you find the Bayes factor \(BF_{0A}\)?

This can be solved analytically.

# calculate both likelihoods under the null hypothesis
null_Lp <- dnorm(x = data_placebo, mean = 2, sd = sqrt(8)) %>% cumprod %>% tail(1)
null_Lc <- dnorm(x = data_calcium, mean = 2, sd = sqrt(8)) %>% cumprod %>% tail(1)

# calculate both likelihoods under the alternative hypothesis
alt_Lp <- dnorm(x = data_placebo, mean = 0, sd = sqrt(8)) %>% cumprod %>% tail(1)
alt_Lc <- dnorm(x = data_calcium, mean = 4, sd = sqrt(8)) %>% cumprod %>% tail(1)

# combine likelihoods
num <- null_Lp * null_Lc
denom <- alt_Lp * alt_Lc

# calculate bayes factor
num / denom
[1] 0.0002034684
# NOTE: likelihood values become very small, so can use log scale instead (i.e log both sides and simplify)
# -> just have to adjust operations accordingly
# -> using new notation here; and BF_0A = exp(loglik_0 - loglik_A
l_H0 <- sum(dnorm(x = data_placebo, mean = 2, sd = sqrt(8), log = TRUE)) + sum(dnorm(x = data_calcium, mean = 2, sd = sqrt(8), log = TRUE)) 
l_HA <- sum(dnorm(x = data_placebo, mean = 0, sd = sqrt(8), log = TRUE)) + sum(dnorm(x = data_calcium, mean = 4, sd = sqrt(8), log = TRUE)) 
exp(l_H0 - l_HA)
[1] 0.0002034684

Using the rule of thumb (\(BF_{0A} < 0.01\)) for the Bayes Factor calculated above, there is decisive evidence against the null hypothesis models.

Note because there are no unknown parameters under each hypothesis, bridgesampling::bridge_sampler() isn’t necessary to solve this problem. Bridge sampling is designed to approximate marginal likelihoods obtained by integrating over unknown parameters, and here there is no integration to perform.
